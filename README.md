# 摸鱼箱子_05

一个无需安装依赖的纯前端课间小游戏合集。项目名称为“摸鱼箱子_05”，其中 `05` 是学号后两位；当前 GitHub 仓库为 [xfan371/-_05](https://github.com/xfan371/-_05)。

## 现有功能

- 赛博运势：随机生成今日宜忌、Bug 概率（纯娱乐）。
- 点名雷达：根据所选条件生成虚构概率；请正常上课，不作为缺课依据。
- 电子宠物：点击聊天、喂食并记录当前页面的投喂次数。
- 废话生成器：输入称呼，生成彩虹屁或轻度吐槽。
- Bug 模拟器：对输入文本随机做一次简单替换；不会执行或上传代码。

## 运行

直接双击 `index.html` 即可运行，手机或电脑浏览器均可访问。不需要 Node.js、服务器、账户或联网。
